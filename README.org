#+title: git-bug.el — Magit sections for the git-bug bug tracker

Adds a collapsible "Bugs" section to =magit-status= buffers listing the
bugs of the [[https://github.com/MichaelMure/git-bug][git-bug]] distributed bug tracker, which stores them in the
repository's own =refs/bugs/*= references.

* Usage

Add the section inserter to the status sections hook:

#+begin_src emacs-lisp
(add-hook 'magit-status-sections-hook #'git-bug-insert-status-bugs 100)
#+end_src

Every bug is a collapsible section; expand it to see its labels,
description and comments.
Bug bodies are fontified as Markdown with the builtin
=markdown-ts-mode= when its tree-sitter grammars are installed;
Markdown markup symbols are then hidden.
On a bug heading:

- =RET= opens the bug in a dedicated buffer
- =w= copies the short id
- =x= flips the open/closed status

On the =Bugs= heading, =n= creates a bug.  The compose buffer uses
=C-c C-c= to submit and =C-c C-k= to cancel.

Which bugs are listed is controlled by =git-bug-status-section-scope=
(=open=, =closed= or =all=; default =open=).
The heading always shows the listed count over the total.

* Requirements

- Emacs 31.1
- Magit 4.0
- the =git-bug= binary (its path is baked in when built with Nix)
- optional: the tree-sitter grammars =markdown= and =markdown-inline=
  (=M-x treesit-install-language-grammar=; for Markdown fontification
  of bug bodies)

* Building

#+begin_src sh
nix build          # byte-compile (warnings as errors) + ERT suite
nix flake check    # package + tests + checkdoc + package-lint
nix fmt            # format via treefmt
#+end_src

The ERT suite drives the real =git-bug= binary inside throwaway
repositories, so =git= and =git-bug= are needed during the build.
The dev shell provides Emacs with Magit and exports
=MARKDOWN_GRAMMARS= with the tree-sitter grammars for Markdown
fontification.  For ad-hoc tests:

#+begin_src sh
nix develop
emacs -Q --batch -L . \
  --eval '(setq treesit-extra-load-path (list (getenv "MARKDOWN_GRAMMARS")))' \
  -l git-bug-tests.el -f ert-run-tests-batch-and-exit
#+end_src
